# Astrosage-Call-Analysis
## 📌 Project Overview

AstroSage Call Analysis project focuses on analyzing AstroSage call data to identify
important patterns, trends, and insights from the available data.
The project includes exploratory analysis, answers to objective and
subjective business questions, and a storytelling presentation
summarizing the key findings.
## 🎯 Project Objectives

- Analyze the call data
- Identify important trends and patterns
- Answer the defined objective questions
- Answer the subjective/business questions
- Generate meaningful insights
- Present the findings through data storytelling

## 🛠️ Tools Used

- Microsoft Excel
- Data Cleaning
- Data Analysis
- Pivot Tables
- Charts and Visualization
- Data Storytelling

## 📊 Project Deliverables

### 1. Analysis & Questions

The DOCX file contains the completed objective and subjective
questions along with the analysis performed for the project.

### 2. Storytelling Presentation

The PowerPoint presentation communicates the major findings and
insights from the analysis.

### 3. Project Documentation

The project documentation provides the complete project output
and supporting analysis.
